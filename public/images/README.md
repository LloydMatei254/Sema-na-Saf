# Kenya Map Image

To use your custom Kenya map JPEG image:

1. Save your JPEG image as `kenya-map.jpg` in this directory (`public/images/`)
2. The image will automatically be loaded by the KenyaMap component
3. The component applies a green filter overlay to match the Safaricom theme

## Image Requirements
- Format: JPEG or PNG
- Recommended size: 800x600 pixels or higher
- The image should show Kenya with clear county boundaries
- Counties should be clearly labeled for optimal user experience

## Current Status
